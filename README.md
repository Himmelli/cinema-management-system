
# Cinema Management System

Cinema Management and Online Ticket Booking System

## Technology Stack
- Backend: Java, Spring Boot
- Frontend: React, TypeScript, Vite
- Database: PostgreSQL
- Authentication: Spring Security, JWT
- Payment: VNPAY Sandbox

## Project Structure
- cinema-backend: REST API and business logic
- cinema-frontend: Customer and Admin website

## Main Features
- User authentication and authorization
- Movie and cinema management
- Showtime and seat management
- Online ticket booking
- Payment and QR ticket generation
- Revenue reporting
